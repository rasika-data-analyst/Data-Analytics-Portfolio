# Czechoslovakia Bank Analysis

## Project Overview
This project analyzes banking data using SQL and Power BI to explore financial performance, customer behavior, and key business trends.

## Tools Used
- SQL — data analysis and business queries
- Power BI — interactive dashboard and data visualization

## Project Objectives
- Analyze banking data to identify meaningful business patterns.
- Answer business questions using SQL queries.
- Present key findings through a Power BI dashboard.
- Support data-driven business decisions.

## Project Files
- `Czechoslovakia_Bank_Dashboard.pbix` — Power BI dashboard
- SQL analysis scripts — business queries and analysis
- Project documentation — methodology, findings, and explanations

## Key Learnings
- Writing SQL queries for business analysis
- Translating business questions into analytical queries
- Building interactive Power BI reports
- Communicating insights to stakeholders
